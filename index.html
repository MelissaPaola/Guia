Comandos essenciais do Git para consultar rapidamente.

Comandos Essenciais:

git init

O git init é o comando do Git usado para transformar uma pasta comum do computador em um repositório Git vazio.

git add .

O comando git add . serve para preparar todos os arquivos novos, modificados ou excluídos da sua pasta atual para serem salvos no histórico do Git.

git commit -m ["mensagem de commit"]

O comando git commit -m serve para salvar permanentemente as alterações preparadas no repositório local do Git.

git push -u origin main

O comando serve para enviar seus arquivos para o GitHub pela primeira vez e criar uma conexão direta entre o seu computador e a internet.

git status

O "git status" mostra o estado atual do projeto, indicando quais arquivos foram modificados, adicionados ou ainda não estão sendo acompanhados pelo Git.

git log

O"git log" exibe o histórico de commits do projeto, mostrando as alterações que foram registradas ao longo do tempo.

git clone

O "git clone" copia um repositório remoto para o computador, permitindo trabalhar com o projeto localmente.

git pull

O "git pull" baixa as alterações mais recentes do repositório remoto e atualiza o projeto local.

git fetch

Verifica se o repositório remoto tem modificações em relação ao local.

git remote add origin [link do repositório]

Conecta o repositório local ao repositório remoto.
