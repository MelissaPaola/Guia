Comandos essenciais ✿

git init

Transforma uma pasta comum em um repositório Git para começar a acompanhar as alterações do projeto.

git add .

Prepara os arquivos novos, modificados ou excluídos para serem incluídos no próximo commit.

git commit

Registra no histórico do repositório as alterações que foram preparadas para o commit.

git push

Envia os commits locais para o repositório remoto, como o GitHub.

git status

Mostra quais arquivos foram modificados, adicionados ou ainda não estão sendo acompanhados.

git log

Exibe o histórico de commits e informações sobre as alterações registradas.

git clone

Copia um repositório remoto para o computador, permitindo trabalhar com o projeto localmente.

git pull

Busca as alterações do repositório remoto e integra as atualizações ao projeto local.

git fetch

Busca informações e atualizações do repositório remoto sem integrá-las automaticamente à sua branch.

git remote add origin

Configura um endereço remoto chamado origin para conectar seu repositório local ao remoto.

Dica: não se esqueça de dar o commit! ✿
